# ¡Hola! Soy Candelaria 👋

### Frontend Developer · Angular · React · UI/UX

Soy **Frontend Developer** con casi 5 años de experiencia profesional, principalmente trabajando con **Angular** en equipos y entornos de startup.

Me gusta crear interfaces **claras, funcionales y agradables de usar**, combinando desarrollo frontend con mi formación en **Diseño Gráfico** y mi interés por UI/UX.

Antes de dedicarme al desarrollo estudié Diseño Gráfico, y esa experiencia sigue formando parte de mi manera de trabajar: me interesa tanto **cómo funciona una interfaz como cómo se ve y cómo interactúa el usuario con ella**.

Actualmente estoy ampliando mi stack hacia **React, TypeScript y Node.js**, desarrollando proyectos propios y colaborativos mientras continúo creciendo como desarrolladora frontend.
