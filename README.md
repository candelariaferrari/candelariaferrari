## 🚀 Proyectos destacados

### 💳 NomaPay — Billetera virtual multi-moneda
Proyecto final grupal donde lideré el frontend: UX, sistema de diseño, arquitectura de carpetas y flujo de Git del equipo. Desarrollé las pantallas de dashboard, historial, configuración y transferencias sobre una billetera con compra/venta e intercambio entre monedas a tasas reales, con confirmaciones por email (AWS SES) y un chatbot asistente con Gemini.

**Stack:** React · TypeScript · Tailwind CSS · Firebase · Vercel

---

### 🛍️ E-commerce Full Stack
Tienda online con roles de cliente y administrador: catálogo filtrable, carrito con Context API, checkout con órdenes y panel admin con CRUD de productos. Autenticación con Firebase (email/Google) y upload de imágenes a AWS S3 vía funciones serverless. Cobertura de tests con Vitest y React Testing Library.

**Stack:** React · TypeScript · Firebase · AWS S3 · Vitest

---

### 📝 MiniBlog DevSpark
API REST tipo JSONPlaceholder con autores y posts, documentada con Swagger.

**Stack:** Node.js · Express · PostgreSQL · Swagger · Railway

---

### 📋 For Today
To-do app con autenticación (email/Google), persistencia por usuario en Firestore y envío de resumen de tareas por email vía AWS SES.

**Stack:** React · TypeScript · Firebase · AWS SES

---

### 💬 Chat con tus Emociones
Chatbot conversacional con personajes de Intensamente, integrado con la API de Gemini.

**Stack:** JavaScript · Gemini API · Vercel

---

### 🎨 Generador de Paletas de Colores
Herramienta para generar paletas aleatorias (6, 8 o 9 colores), con bloqueo de colores, copiado al portapapeles y guardado en localStorage.

**Stack:** HTML · CSS · JavaScript · GitHub Pages
